<h1 align="center">RiV Mail</h1>

<p align="center">Discord ModMail & Ticket Bot built with Python and discord.py.</p>

---

## Features

<table>
<tr>
<td width="33%" valign="top">

**ModMail**

- ModMail system
- Staff ticket management
- Ticket claiming
- Ticket history

</td>
<td width="33%" valign="top">

**Tickets**

- Transcripts
- Ticket notes
- Custom replies
- Snippets
- Reason management

</td>
<td width="33%" valign="top">

**Management**

- Blacklist system
- SQLite database
- Emoji Uploader
- Slash & prefix commands
- `.env` configuration

</td>
</tr>
</table>

## Setup

<table>
<tr>
<td><b>1. Clone</b></td>
<td>

```bash
git clone [repository urlll]
cd "RiV MiaL"
```

</td>
</tr>
<tr>
<td><b>2. Install</b></td>
<td>

```bash
pip install -r requirements.txt
```

</td>
</tr>
<tr>
<td><b>3. Configure</b></td>
<td>

Create a `.env` file:

```env
BOT_TOKEN=YOUR_BOT_TOKEN
OWNER_IDS=YOUR_DISCORD_ID
```

</td>
</tr>
<tr>
<td><b>4. Run</b></td>
<td>

```bash
python main.py
```

</td>
</tr>
</table>
